# Virtual Machine Lab

This repository contains my practical work, experiments, configurations, and documentation for the **Virtual Machine (VM) Lab**.

The lab focuses on understanding virtualization, creating and managing virtual machines, configuring virtual hardware, installing operating systems, and performing different practical tasks using virtualized environments.

- Oracle VirtualBox
- Ubuntu Linux
- Windows
- Virtual Machines
- ISO Images
- Virtual Hard Disks
- Linux Terminal

## ⚙️ Virtual Machine Configuration

The VM configurations used in the lab may include:

- **Hypervisor:** Oracle VirtualBox
- **Guest OS:** Ubuntu Linux
- **Architecture:** 64-bit
- **RAM:** 4 GB
- **CPU:** 2 cores
- **Virtual Disk:** 25 GB
- **Graphics Controller:** VMSVGA
- **Video Memory:** 128 MB
- **Network:** NAT
